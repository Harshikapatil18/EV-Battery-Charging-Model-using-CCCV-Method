# EV Battery Charging Model Using CCCV Method

## Overview

This project implements an Electric Vehicle (EV) battery charging model based on the **Constant Current–Constant Voltage (CCCV)** charging technique, one of the most widely used methods for charging lithium-ion batteries. The model simulates the charging process by initially supplying a constant current until the battery reaches a predefined voltage threshold, followed by a constant voltage phase where the charging current gradually decreases.

The objective of this project is to analyze battery charging behavior, improve charging efficiency, and ensure safe battery operation by preventing overcharging and excessive current flow.

## Features

* Implementation of the CCCV charging algorithm
* Constant Current (CC) charging phase simulation
* Constant Voltage (CV) charging phase simulation
* Battery voltage and current monitoring
* State of Charge (SoC) analysis
* Safe and efficient charging strategy
* Performance evaluation of charging characteristics

## Technologies Used

* MATLAB/Simulink
* Battery Modeling
* Power Electronics
* EV Charging Systems
* Control System Design

## Methodology

1. Develop a battery model representing EV battery characteristics.
2. Apply a constant charging current until the battery reaches the target voltage.
3. Switch to constant voltage mode while reducing charging current gradually.
4. Monitor battery voltage, current, and State of Charge (SoC).
5. Analyze charging performance and battery behavior throughout the charging cycle.

## Applications

* Electric Vehicle Battery Management Systems (BMS)
* EV Charging Infrastructure
* Battery Performance Analysis
* Energy Storage Systems
* Power Electronics Research

## Outcome

The project successfully demonstrates the CCCV charging process for EV batteries, highlighting its effectiveness in achieving safe, reliable, and efficient charging. The model provides valuable insights into battery charging dynamics and supports the development of advanced battery management and charging solutions.
